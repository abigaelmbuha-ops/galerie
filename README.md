# Ma Galerie Personnelle - Kahindo Mbuhavinywa Abigael

## Présentation
Galerie personnelle de Kahindo Mbuhavinywa Abigael. Elle présente 3 photos cliquables sur le thème de l'élégance et de la mode, avec une description pour chacune. Quand on clique sur une photo, elle s'affiche en grand. Butembo / Goma.

## Technologies utilisées
- HTML
- CSS
- JavaScript pour ouvrir les photos en grand
- Cloudinary pour héberger les images
- GitHub Pages pour publier le site

## Comment Cloudinary est utilisé
Les 3 images sont téléversées dans la bibliothèque Cloudinary. La galerie n'a pas les images dans son dossier. Elle affiche les images directement avec leurs liens Cloudinary (res.cloudinary.com).

## Comment exécuter le projet localement
1. Télécharger le projet
2. Ouvrir le fichier index.html dans le navigateur
3. Cliquer sur une photo pour la voir en grand
